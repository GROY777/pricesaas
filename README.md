# PriceSnap

Прототип сервиса печати ценников: FastAPI и PostgreSQL, Telegram Mini App и Windows-агент. Для работы Telegram Mini App требуется публичный HTTPS-адрес.

## Запуск

1. Скопируйте `.env.example` в `.env`, задайте уникальные пароль PostgreSQL и длинный случайный `JWT_SECRET`. Пароль в `DATABASE_URL` должен совпадать с `POSTGRES_PASSWORD`; специальные символы в URL нужно кодировать.
2. Укажите `BOT_TOKEN`, `BOT_USERNAME`, публичный HTTPS `WEBAPP_URL` и данные ЮKassa. Без токена бот не запускается; без данных ЮKassa оплата недоступна.
3. Выполните `docker compose up --build -d`. Nginx слушает порт 80; установите перед ним HTTPS-прокси с сертификатом для публичного домена.
4. Зарегистрируйте магазин и скачайте Windows-агент из кабинета. Файл `PriceAgent_Setup.exe` — готовая программа, не мастер установки; для пересборки см. `agent/build_instructions.md`.
5. Скопируйте ссылку приглашения в кабинете, откройте её в Telegram и запустите сканер. Ссылка даёт право присоединиться к магазину; её можно отозвать в кабинете.

Данные PostgreSQL и PDF хранятся в Docker volumes `postgres_data` и `media_data`. Создавайте их резервные копии. При первом запуске приложение создаёт таблицы; также автоматически добавляется отдельный токен приглашения в ранее созданную таблицу магазинов.

## Локальная проверка

Установите зависимости из `backend/requirements.txt` и дополнительно `pypdf`, затем из каталога `backend` выполните `python -m unittest discover -s tests -v`. Для сквозной проверки нужны PostgreSQL, Telegram-бот, тестовый магазин ЮKassa и Windows с принтером.

## Ограничения

До промышленного запуска нужны сквозные испытания, миграции схемы с управлением версиями, мониторинг и резервное копирование. Задание выдаётся одному агенту на две минуты; после истечения срока оно может быть выдано повторно. Если печать началась, но подтверждение потерялось, повторная печать возможна: физический принтер и сервер не участвуют в общей транзакции. Подтверждение отправки задания принтеру не гарантирует физическую печать. Токены МойСклад хранятся в базе в открытом виде, поэтому защитите доступ к базе и резервным копиям. Синхронизация использует первую продажную цену и не удаляет товары, исчезнувшие из МойСклад.
